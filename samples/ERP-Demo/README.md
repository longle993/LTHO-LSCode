# LS Code demo

Mở thư mục này trong LS Code để thử Explorer, SQL/XML editor và search.

- `voucher.xml`: XML minh họa có tiếng Việt, attributes, comment và CDATA. Không phải mẫu nghiệp vụ để triển khai lên FAST.
- `query.sql`: hai batch chỉ đọc để thử SQL results khi đã cấu hình database.

Ctrl+P mở file, Ctrl+Shift+P mở lệnh, Ctrl+\ chia editor, Ctrl+F tìm trong file, Ctrl+Shift+F tìm workspace. SQL: Ctrl+Space gợi ý keyword, F5 chạy vùng chọn hoặc cả document.
